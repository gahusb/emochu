| **1** | **당일 중복 실행 금지 규칙**이 3개 Loop 전부에 있다 | 오전 RED → 오후 수정 → **재확인이 거부된다.** `tourapi-watch`(일일 표본)엔 맞지만 나머지 둘은 하루에도 상태가 바뀐다. ⚠️ 다만 스크립트가 **같은 경로를 덮어쓰므로**, 규칙만 풀면 오전 RED 증거가 사라진다 — 파일명에 시각을 넣는 게 같이 필요 |

| **3** | **`Bash(git commit:*)` deny가 레포 전체에 걸린다** | Loop 세션만이 아니라 **이 레포의 모든 Claude 세션**에 적용되고, deny는 프롬프트로 못 푼다. 내일 평범한 커밋도 막힌다. `CLAUDE.md`에 한 줄 명시하거나 정책을 조정할 것 |
| **4** | **`verifier.md`가 `tourapi-watch` 전용**(6곳 하드코딩) | 나머지 두 Loop는 검증자가 없어 자기 채점 상태다 |
| **5** | `submission.json` 의 `auto` 항목에 있는 `done` 필드는 **아무 효과가 없다** | 기계 검사만 반영된다. 사람이 만지면 헛수고 |

### 자잘한 것

- `hooks` 커맨드가 상대경로 — 문서 권장은 `${CLAUDE_PROJECT_DIR}` 앵커
- `lint-changed.mjs`의 `readFileSync(0)`는 **TTY에 붙으면 블록**된다. 손으로 디버깅할 때 멈춘다(실사용은 항상 파이프라 무해)
- `spawnSync(shell:true)` 인자 미이스케이프 (Node DEP0190) — 현재 무해
- `gate.mjs`는 `.env.local`만 읽는다. `.env`에만 있는 값은 유출 대조에서 빠진다
- `gate.mjs`의 테스트 개수 추출이 출력 **마지막 6줄**만 본다 — 실패 시 WARN으로 안전하게 떨어지나 불필요하게 좁다
- `smoke.mjs`의 최종 유출 확인이 `encodeURIComponent(KEY)`는 안 본다(`mask()`는 봄)
- `checkAttribution`이 STRICT 히트 시 조기 반환해 **파싱 실패 파일 목록이 부분적**일 수 있다 (판정은 정확, 진단만 불완전)
- `loops/tourapi-watch/TASK.md`·`SKILL.md`가 *"`.env.local`은 읽기 자체가 금지"*라고 쓰는데 **레포 차원에선 사실이 아니다** — deny는 *에이전트 컨텍스트*를 지키는 것이고, allow된 스크립트 둘은 실제로 읽는다(값은 출력 안 함). 문장이 오해를 부른다

## ⚠️ 되풀이하지 말 것 (실제로 겪은 것)

1. **PostToolUse 훅은 `CLAUDE_FILE_PATH` 같은 환경변수를 받지 않는다.** **stdin JSON**의 `tool_input.file_path`다. 초판이 이걸 틀려 훅이 **영구 무동작**이었다.
2. **`--max-warnings 0`을 훅에 쓰지 않는다.** 이 레포엔 기존 경고 12건/7파일이 있고 `eslint.config.mjs`가 `react-hooks/set-state-in-effect`를 *의도적으로* warn으로 낮춰 뒀다. 훅이 그걸 뒤엎으면 매 편집마다 시끄러워진다.
3. **`NEXT_PUBLIC_*`는 비밀이 아니다**(이 레포에 9건). 유출 대조에 넣으면 RED 경로에서 **진짜 빌드 오류의 진단문을 오탐 마스킹**한다.
4. **출처 표기 검사는 세 번 뚫렸다** — 주석 매치 → 블록주석이 줄번호 붕괴 → 여는 `/*` off-by-one → **정규식 리터럴이 파서를 문자열 상태에 가둠**(`app/api/spot/route.ts:180`의 `/href="([^"]+)"/`). 지금은 **파서가 `code` 상태로 끝나지 못한 파일을 신뢰하지 않는다.** 이 검사기를 손볼 땐 이 네 경로를 전부 다시 확인할 것.
5. **테스트 개수를 판정에 넣어야 한다.** 안 넣으면 61→10으로 줄어도 ✅ GREEN + exit 0이 나온다.
6. **"scrub이 돌았다"와 "비밀이 없다"는 다른 주장이다.** 체크리스트에 하드코딩하지 말고 실제 값과 대조할 것.
