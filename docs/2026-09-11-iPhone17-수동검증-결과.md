## 검증 상태 갱신

- **기본 수동 검사: 특이사항 없음(사용자 보고).** 홈 확대, 축제 필터, 상세·지도, 입력 흐름을 안내한 뒤 받은 응답이다. 사진에서 직접 확인한 범위는 위 표로 구분한다.
- 기존 ‘실제 폰 제어 경로가 없어 검증 전체 대기’ 상태는 해소됐다. PC 연결이나 원격 제어 없이도 사용자 참여로 실기기 검사를 진행했다.
- 9/10 배포 DOM에서 `maximum-scale=1`을 관측한 사실은 유지한다. 그러나 이것을 **이번 iPhone에서 실제 확대가 막혔다는 결함으로 표현하지 않는다.** 로컬의 해당 속성 제거와 배포 일치 확인은 별도 항목이다.
- 9/10 반경 버튼 약 29.3px 실측은 인앱 브라우저의 당시 값이다. 이번 사용자가 오탭을 보고하지 않았다고 해서 44px 목표 충족이나 접근성 전반 통과로 변경하지 않는다.
- ‘문 여는 곳으로만’이라는 로컬 잔여 문구와 운영시간 미확인 문제는 이번 화면 검사로 해결된 것이 아니다.
