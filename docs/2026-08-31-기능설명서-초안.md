## 서비스 개요

한국관광공사 TourAPI와 AI를 결합한 **주말 나들이 코스 초개인화 큐레이션 서비스**.

사용자가 **6가지 컨텍스트**(목적지·기분·시간·동반자·취향·**접근성**)를 선택하면, AI가 한국관광공사 실시간 공식 데이터를 분석해 **동선까지 고려한 맞춤형 코스**를 설계하고 카카오톡 공유까지 지원하는 **원스톱 서비스**다.

단순한 유명 장소 나열을 넘어, TourAPI로 **숨겨진 지역 명소와 진행 중인 축제**를 코스에 자연스럽게 녹여 **「발견의 경험」**을 제공한다.

## 주제 선정 이유

*"주말에 뭐 하지?"* 는 매주 반복되는 고민이다. 블로그와 SNS를 헤매다 **의사결정 피로**에 지쳐 결국 늘 가던 곳으로 향한다.

이모추는 이 **탐색의 피로**를 몇 번의 탭으로 끝낸다. 그리고 여기에 **두 가지 관점**을 더했다:

1. **「진짜 갈 수 있는 코스」** — 방문 요일에 문을 닫는 곳은 코스에 넣지 않는다. 추천은 실행 가능해야 의미가 있다.
2. **「누구나 갈 수 있는 코스」** — 이동·시각·청각·영유아 동반 조건을 반영한다. 관광 정보의 접근성은 아직 크게 비어 있다.

> 한국관광공사 **2026 관광 트렌드 「D.U.A.L.I.S.M.」** 중 **Digital Humanity**(맥락을 이해하는 AI 조력자) · **Spatial Experience**(시간 흐름에 따른 공간 경험) · **Local Re-creation**(지역 고유 가치 재발견) 3가지 키워드를 서비스로 구현했다.

# 3. 핵심 기능별 흐름도 (최대 5개)

## 기능 ①. AI 코스 생성 위저드 (6단계)

**하이브리드 아키텍처** — AI 환각을 막기 위해 **결정론적 규칙으로 후보를 먼저 좁히고**, AI는 좁혀진 후보 안에서 **순서·시간 배치만** 담당한다.

```
[1] 목적지  내 주변(GPS) / 도시 선택 / 무드(산·바다·계곡·도심·시골)
[2] 기분    지침 · 에너지 · 로맨틱 · 힐링 · 모험 · 맛집  (6종)
[3] 시간    반나절 · 하루 · 여유롭게 · 1박2일
[4] 동반자  혼자 · 연인 · 가족 · 친구
[5] 취향    자연 · 맛집 · 문화 · 카페 · 액티비티 · 사진  (복수)
[6] 접근성  이동 · 시각 · 청각 · 영유아 동반  (선택)
                    │
                    ▼
   TourAPI 동시 다중 호출 (Promise.all)
   locationBasedList2 · searchFestival2 · searchStay2 …
                    │
                    ▼
   결정론적 스코어링 — 기분·동반자·취향·날씨 가중
                    │
                    ▼
   AI(Gemini)가 순서·시간 배치  ←  A/B 두 코스 병렬 생성
                    │
                    ▼
   자체 검증 — contentId 교차검증 · Haversine 이동거리 재계산
                    │
                    ▼
   타임라인 + 카카오맵 (관광지·맛집·카페·축제·숙박 5색 구분)
```

## 기능 ②. ⭐ 무장애 맞춤 코스 — 누구나 갈 수 있는 코스

접근성 조건을 고르면 **무장애 여행 정보 API**(`KorWithService2 / detailWithTour2`)로 후보를 걸러낸다.

```
접근성 선택 (이동·시각·청각·영유아)
        │
        ▼
후보 contentId 목록 → detailWithTour2 조회
        │
        ▼
조건 미충족 장소 제외 → 코스에 무장애 정보 표시
```

**설계상 배려 2가지** — 실제 코드가 그렇다:
- 접근성 조건이 **없으면 API를 호출조차 하지 않는다** → 기존 사용자 응답 지연 **0**
- 조회가 **실패해도**(403·타임아웃·429) **빈 결과로 코스 생성은 계속된다** → 서비스가 멈추지 않는다

## 기능 ③. ⭐ 「진짜 갈 수 있는 코스」 — 휴무일 반영

추천받은 곳이 그날 문을 닫으면 추천이 아니다. **방문 요일을 받아 휴무일을 파싱해 제외**한다.

```
방문일 선택 (토 / 일)
        │
        ▼
detailIntro2 의 비정형 휴무 텍스트 파싱
  · 요일 범위 확장      "금~일요일"  → 금·토·일
  · 연중무휴 패턴 인식  "연중무휴" 등
  · 단어 경계 판정      "공휴일"·"익일" 오탐 방지
        │
        ▼
해당 요일 휴무 장소를 코스에서 제외
```

## 기능 ④. 통합 장소 상세 + 원클릭 공유

- **비정형 데이터 정제** — `detailIntro2` 의 25개 이상 비정형 필드에서 **의사결정에 중요한 5대 신호**(주차·유모차·키즈·반려동물·운영시간)만 자동 추출해 카드로 제공
- **모달 + 영구 URL 동시 지원** (Next.js Intercepting Routes)
- 코스마다 **고유 URL + OG 썸네일 자동 생성** → 카카오톡 공유 최적화

## 기능 ⑤. 실시간 축제 매거진

진행 중 · 이번 주말 · 곧 시작 · D-Day **4단계 상태 뱃지**로 시의성 높은 지역 행사를 즉시 파악한다.

> 🟡 **선택 — 기능 ⑥ 「오늘의 기운」(사주 오행) 개인화**
> 생년과 오늘의 오행 관계로 그날의 기분을 도출해 코스 톤과 후보 가중에 반영한다. **날마다 결과가 달라져 재방문 이유가 된다.**
> 🔴 현재 위저드 안에 **접혀 있어** 노출도가 낮다 — `docs/2026-08-29-킥-사주-인수인계.md` 의 3건을 적용한 뒤 이 항목을 **⑤ 대신 넣을지 재오님이 결정**한다. (핵심 기능은 **최대 5개**)

# 6. 차별성 & 발전 계획

## 차별성

**① 「추천」이 아니라 「실행 가능한 코스」다**
방문 요일 휴무를 파싱해 제외하고, 이동거리를 자체 계산(Haversine)해 동선을 검증한다. **가서 문이 닫혀 있으면 추천이 아니다.**

**② 접근성을 부가 기능이 아니라 코스 생성 조건으로 넣었다**
무장애 정보를 **후보 필터링 단계**에서 쓴다. 조건이 없으면 호출조차 하지 않고, 실패해도 서비스가 멈추지 않도록 설계했다.

**③ 하이브리드 AI 아키텍처 — 환각 방지**
결정론적 규칙으로 후보를 좁히고 AI는 배치만 담당한다. contentId 교차검증으로 **존재하지 않는 장소가 나오지 않는다.**

**④ 다중 API 통합 파이프라인**
필수 요건(3개 이상)을 크게 넘는 **2종 12개 오퍼레이션**을 단일 코스 객체로 실시간 결합한다.

**⑤ 비정형 데이터의 사용자 친화적 정제**
25개 이상 비정형 필드에서 **5대 핵심 신호만** 자동 추출해 직관적 카드로 제공한다.

**⑥ ⭐ 약속한 것을 이행했다**
예비심사 제안서의 **「Phase 1. 무장애 관광 포용」을 실제 구현**했다. 계획서의 문장이 아니라 **동작하는 기능**으로 증명한다.

## 발전 계획

| 단계 | 내용 |
|---|---|
